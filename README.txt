Where's My Hat? — GitHub Pages deployment package

Upload the contents of this folder to the root of your GitHub repository:

index.html
assets/
  audio/lesson-song.mp3
  images/slide-1.png ... slide-17.png

Keep the folder names and relative paths unchanged.

GitHub Pages settings:
1. Open Settings > Pages.
2. Choose Deploy from a branch.
3. Select main and / (root).
4. Save and wait for deployment.

The lesson contains 26 pages and works through the shared Back, Next,
Full Screen, ArrowLeft, and ArrowRight controls.
